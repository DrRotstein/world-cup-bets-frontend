# world-cup-bets-frontend

Frontend SPA for the World Cup Bets app — a casual friend-group betting pool for FIFA World Cup 2026.

## Stack

- **Framework:** React 18
- **Build:** Vite 5
- **Language:** TypeScript 5
- **Routing:** React Router 6
- **Server state:** TanStack Query 5
- **Deploy:** Railway (static site)

See [ADR-001](https://github.com/DrRotstein/world-cup-bets-docs/blob/main/architecture/adr/ADR-001-stack-choice.md) for the full stack rationale.

## Getting Started

```bash
npm install
npm run dev
```
